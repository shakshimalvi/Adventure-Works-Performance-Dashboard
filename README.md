# Adventure Works Performance Dashboard

A comprehensive **Power BI** sales performance dashboard for Adventure Works, a fictional outdoor and cycling equipment company. This interactive dashboard provides deep insights into sales trends, profitability, regional performance, product categories, and customer behavior.

### 📊 Key Features & Insights

- **Executive KPIs**: Total Sales (₹24.91M), Total Profit (₹10.46M), Profit Margin (41.97%), Return Rate, and YoY Growth
- **Sales Trends**: Monthly sales performance with clear seasonal patterns
- **Category Analysis**: Bikes dominate (94.89% of sales), followed by Accessories and Clothing
- **Geographic Performance**: Sales distribution by region and country with interactive map
- **Profitability Analysis**: Profit margin % by category and return rate % by region
- **Product & Demographic Breakdown**: Sales by product name and gender-wise performance
- **Interactive Filters**: Region, Category, and Year slicers for dynamic exploration

### 🛠️ Technologies Used

- **Power BI Desktop**
- AdventureWorks Sample Database
- DAX Measures
- Data Modeling & Visualization Best Practices

### 🎯 Purpose

This project demonstrates end-to-end business intelligence skills — from data modeling and DAX calculations to creating professional, insightful, and user-friendly dashboards for stakeholders.
